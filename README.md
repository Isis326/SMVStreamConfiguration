Website Description:

This web interface is designed to monitor and configure electrical signal measurements in real time.

It allows users to view, edit, and save phasor data, frequency, phase, and sampled measured values (SMV) with customizable sample rates and data types.



How to Run the Web Page

CMD: Navigate to your project folder smvConfiguratorWebPage using the commands:

cd ..

cd Users

cd 'Username'

cd Desktop

cd smvConfiguratorWebPage



To run locallySs : php -S localhost:8000
Open the browser and enter http://localhost:8000/
